HTML Number Offset Tool

Instructions
  • This tool will increase or decrease all specified numbers in the HTML input. Leading zeroes are retained. Negative offsets are possible, and will never output a number less than 1.
  • Enter one of: the HTML tags, tag contents, or attributes you want to modify. Separate more than one element with spaces ("div span"). Or, use plain text mode to change all numbers. Or, use a regex containing "\d+" to match certain things.
  • "Tag contents" are the visible text output of HTML, e.g. index page numbers. Only the first "parent" HTML tag with a number will be affected. In [div][a]123[/a][/div], the number will change only if "a" is specified, not "div".
  • Limitations: 1) The tool is meant for integers, and does not take into consideration commas and decimal points. Each of the three numbers in "123,456.789" will be changed. 2) Roman numerals are not affected. 3) Careful about pasting an entire HTML document in—tags like html, head, and body are currently dropped in "Tag contents" mode.
  • It is strongly recommended to compare the before and after text with a diff.
